Contoh dossier: 8.8.8.8

dezz dossier 8.8.8.8 menebak jenis target (IP), menjalankan mesin yang cocok, menampilkan tiap seksi di terminal, dan menyimpan arsip JSON-nya. Potongan arsipnya — nilai asli dari pengecekan 19 Nov 2026:

Install & jalanin

  1. Clone + install. 
    git clone https://github.com/dezzorigin/dezz-osint.git
cd dezz-osint
python3 -m venv .venv && source .venv/bin/activate
pip install .
dezz phone +6281234567890
  2. Atau satu perintah. 
    curl -sSL https://raw.githubusercontent.com/dezzorigin/dezz-osint/main/install.sh | bash
  3. Kunci opsional. cp .env.example .env lalu isi yang perlu saja (GITHUB_TOKEN, GOOGLE_API_KEY + GOOGLE_CX). Semua perintah inti jalan tanpanya — dan .env tidak pernah ke-commit.
